=====================================================
🏹 তীরন্দাজ আপেল শিকার - Apple Archery Game
=====================================================

এই জিপ ফাইলটিতে পিওর HTML, CSS ও JavaScript কোড রয়েছে।
কোনো npm install বা অতিরিক্ত সফটওয়্যার ছাড়াই এটি চলবে!

-----------------------------------------------------
১. নিজের কম্পিউটারে অফলাইনে খেলতে:
-----------------------------------------------------
- জিপ ফাইলটি আনজিপ (Extract) করুন।
- সরাসরি 'index.html' ফাইলটিতে ডাবল ক্লিক করুন।
- যেকোনো ব্রাউজারে (Chrome, Edge, Firefox) গেমটি চালু হয়ে যাবে।

-----------------------------------------------------
২. Netlify-তে সম্পূর্ণ ফ্রিতে হোস্ট করতে (মাত্র ১ মিনিট):
-----------------------------------------------------
উপায় ১ (Netlify Drop - সবচেয়ে সহজ):
1. ব্রাউজারে যান: https://app.netlify.com/drop
2. এই জিপ ফাইলটি আনজিপ করে ফোল্ডারটি (অথবা সরাসরি জিপ ফাইলটি) ড্র্যাগ করে ছেড়ে দিন।
3. সাথে সাথে আপনার গেমটি লাইভ হয়ে যাবে এবং একটি পাবলিক লিংক পেয়ে যাবেন!

উপায় ২ (GitHub দিয়ে):
1. আপনার GitHub-এ এই ফোল্ডারের ফাইলগুলো আপলোড করুন।
2. Netlify ড্যাশবোর্ডে গিয়ে "Import an existing project" দিয়ে রিপোজিটরিটি সিলেক্ট করুন।

-----------------------------------------------------
গেমের নিয়ম:
- মাউস বা টাচস্ক্রিন দিয়ে ধনুক পেছনে টানুন এবং নিশানা করে তীর ছুড়ুন।
- প্রতি সফল আপেল টার্গেটে পাবেন ১০ পয়েন্ট (+10 Points)।
- প্রতিটি ধাপে গতি, বাতাস ও ঘোরন্ত ঢালের কারণে খেলা কঠিন হতে থাকবে!

শুভ তীরন্দাজি! 🎯
